**Капля следит за вашими ИИ-агентами и вставляет быстрее.**

- **Claude Code и Codex.** Подключите их в разделе «Агенты» — Капля в вырезе камеры покажет, что агент работает, какой шаг его плана идёт и что он делает прямо сейчас, а когда закончит — скажет об этом. Если агент задал вопрос с вариантами ответа, Капля станет фиолетовой; если просит разрешения — можно разрешить или запретить прямо из Капли. Кнопка «Открыть» ведёт к агенту. Для Codex один раз доверьте хуки Utter в окне «Проверка хуков», которое Codex покажет в новом чате.
- **Клавиша «Задача»** (по умолчанию правый ⌃): говорите как получается — Utter вставит чёткое задание для ИИ-агента.
- **Быстрая вставка.** Диктовка вставляется меньше чем через секунду после того, как вы отпустили клавишу. Перевод иногда ждёт ответа Google чуть дольше — это нормально.

**The Drop watches your AI agents and pastes faster.**

- **Claude Code and Codex.** Connect them in Agents — the Drop in the camera notch shows that an agent is working, which step of its plan it is on and what it is doing right now, and tells you when it is done. When an agent asks a question with options, the Drop turns purple; when it asks for permission, you can allow or deny right from the Drop. Open takes you to the agent. For Codex, trust Utter's hooks once in the «Review hooks» window Codex shows in a new chat.
- **The Task key** (right ⌃ by default): say it however it comes out — Utter pastes a clear task for an AI agent.
- **Fast paste.** Dictation is pasted less than a second after you let go of the key. Translation sometimes waits a little longer for Google — that's expected.
