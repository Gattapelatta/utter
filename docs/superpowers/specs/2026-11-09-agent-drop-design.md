# Капля и ИИ-агенты — спецификация

**Дата:** 2026-11-09. **Статус:** реализовано на `feat/agent-drop` (2026-11-10), проверено вживую с пользователем; итоги и изменения — §8.
**Основная спецификация:** `2026-10-06-utter-design.md` (остров §4.2, ушки §4.2a, онбординг §4.4); черновик в острове — `2026-11-06-live-draft-island-design.md`.

## 1. Зачем

Пользователь даёт задачу ИИ-агенту, уходит в другое окно (у него каждое приложение на весь экран, на своём рабочем столе) и забывает про агента или не знает, когда тот закончил или ждёт ответа. Капля следит за агентами и сама говорит: «работает», «ждёт тебя», «закончил — вот что сделано». Разрешения Claude Code можно давать прямо из острова. Плюс отдельная клавиша, которая превращает сбивчивую речь в чёткую задачу для агента.

**Успех:** человек один раз включает Claude Code и/или Codex — и дальше, с любого рабочего стола, видит у чёлки, что агент закончил или ждёт его, за 1–2 с после события; может ответить на запрос разрешения, не переключаясь; ни одного включённого уведомления и ни одного входа в аккаунт.

## 2. Что выяснили пробой (2026-11-09)

Проверено на Mac пользователя временной программой (удалена, настройки возвращены):

| Источник | Что видно | Вывод |
|---|---|---|
| Claude Code (вкладка Code в Claude, терминал) | Свои «хуки»: `UserPromptSubmit`, `Stop` — приходят из любой сессии и с любого рабочего стола, даже в уже открытой сессии после изменения настроек | **Точный источник.** Берём |
| Codex (режим агента в приложении ChatGPT, у пользователя оно на базе Codex; Codex в терминале) | `notify` → `agent-turn-complete` с `cwd`, `thread-id`, `last-assistant-message` | **Точный источник, только «закончил».** Берём |
| Чат Claude, Cowork, чат ChatGPT | Кнопки «Stop response» / «Остановить» видны через «Универсальный доступ», окна на других столах находятся, **но приложения не обновляют их, пока окно не на экране**; сигналов-хуков нет | **Не берём** в эту версию. Возможно позже |

Уведомления приложений не используем: пользователь не хочет, чтобы их нужно было включать.

## 3. Что делаем

### 3.1 Подключение

- **Раздел настроек «Агенты»**: два переключателя — **Claude Code** и **Codex** (строка под каждым: что это даёт), переключатель **«Итог одной строкой (через Gemini)»** (вкл.), ссылка «Как это работает».
- Включение один раз подключает **весь** агент: все сессии, старые и новые.
- **Claude Code:** Utter дописывает свои хуки в `~/.claude/settings.json` (ключ `hooks`), команда каждого — `<путь к Utter.app>/Contents/MacOS/utter-agent claude <событие>`. Чужие хуки не трогает; при выключении убирает только свои (узнаёт по `utter-agent` в команде).
- **Codex:** в `~/.codex/config.toml` одна строка верхнего уровня `notify = [...]`. Если она уже есть (у пользователя — программа OpenAI «Computer Use»), Utter ставит себя первым и **передаёт** сигнал прежней команде: `notify = ["…/utter-agent", "codex", <прежняя команда и её аргументы>]`. Прежнее значение хранится в настройках Utter и возвращается при выключении. Файл правится построчно, остальное не меняется. Приложение ChatGPT само переписывает этот файл — Utter при запуске проверяет, что его строка на месте, и восстанавливает.
- **Самопроверка при запуске:** если Utter переехал (другой путь к `.app`) или строки пропали — переписывает их; если файл агента повреждён (не JSON/TOML) — не трогает и пишет в разделе «Агенты»: «Не смог подключиться: файл настроек Claude Code повреждён».
- **Онбординг:** новый необязательный шаг **«Подключи агентов»** между «Клавиши» и «Попробуй» — те же два переключателя и одна строка пояснения. Показывается, только если на Mac найден Claude Code (`~/.claude` или Claude.app) или Codex (`~/.codex`). Можно пропустить.

### 3.2 Что Капля показывает (остров)

Ничего не рисуется под вырезом камеры: в покое — только ушки (§4.2a), в раскрытом острове содержимое начинается ниже чёлки (как у острова диктовки). Утверждённые макеты: 5 состояний (2026-11-09). **Цвета, отливы и градиенты — рабочие; подбираем вместе с пользователем отдельным шагом, не как в присланном видео.**

1. **В покое, агент работает:** левое ушко — Капля с цветной точкой состояния (синяя — работает, янтарная — ждёт тебя, зелёная — закончил, пока не посмотрел); правое ушко — по точке на каждого агента (до 4; больше — «+»).
2. **Наведение на ушки** раскрывает остров: по строке на агента — проект (имя папки), агент («Claude Code» / «Codex»), шаг «2 из 4» (если агент ведёт список задач), две последние действия («Прочитал billing.ts», «Правит billing.ts»). Нажатие на строку — «Открыть».
3. **Просит разрешения** (только Claude Code): остров раскрывается сам, янтарный отлив, команда моноширинным (`git push origin main`; для правки файла — имя файла), кнопки **Запретить / Разрешить / Всегда**. Только мышью; горячих клавиш Y/N нет (иначе Utter глотал бы эти буквы в других окнах).
4. **Готово:** раскрывается сам на 6 с, зелёный отлив, «<проект> · Claude Code закончил», **строка итога**, кнопки **Открыть / OK**. Потом сворачивается; зелёная точка остаётся, пока пользователь не откроет агента или не нажмёт OK.
5. **Ждёт ответа** (Claude Code спросил что-то и стоит): как «готово», но янтарная точка и «ждёт твоего ответа».
6. **Несколько агентов:** точки в правом ушке; при раскрытии — список строк, сверху те, кто ждёт.

**Codex** сообщает только «закончил»: у него нет состояния «работает», ленты и разрешений — только «готово» (п. 4) и зелёная точка.

**Очерёдность с диктовкой:** запись, обработка, черновик и ошибки диктовки всегда главнее. Карточка агента, пришедшая во время диктовки, ждёт её конца (запрос разрешения тоже ждёт — его 30-секундный отсчёт начинается, когда карточка показана).

**«Открыть»** выводит на экран приложение, где идёт сессия (Claude, Терминал, iTerm, VS Code, ChatGPT…), вместе с его рабочим столом. Приложение определяется по цепочке родительских процессов `utter-agent` (первый предок-приложение). Открыть конкретную вкладку внутри приложения — только если у приложения есть для этого надёжный способ; проверяется в плане, без него открывается приложение.

### 3.3 Строка итога

- Источник: Claude Code — поле `last_assistant_message` во входе хука `Stop` (файл сессии `transcript_path` пишется с опозданием, документация советует это поле); Codex — `last-assistant-message`.
- Если включено «Итог одной строкой»: текстовая модель выбранного провайдера (по умолчанию Gemini, ключ пользователя), запрос: «одна строка до 70 знаков на языке интерфейса Utter: что сделано; без выдумок». Таймаут 3 с.
- Иначе или при ошибке/таймауте: первая фраза сообщения, обрезанная до 70 знаков по слову.
- В Google уходит только это последнее сообщение агента (как и диктовки) — так написано в разделе «Агенты» и в README (Приватность).

### 3.4 Разрешения из острова (Claude Code)

- Хук `PermissionRequest`: `utter-agent` спрашивает Utter и **ждёт ответа до 30 с** после показа карточки. Нажал «Разрешить» / «Запретить» / «Всегда» — ответ уходит в Claude Code. Не ответил за 30 с, Utter не запущен, на паузе, или нажал «Открыть» — хук возвращается **без решения**, и Claude Code показывает свой обычный вопрос. Утилита никогда не решает сама.
- **«Всегда»** (обязательно, решение пользователя 2026-11-09) = то же, что «Да, больше не спрашивать» в самом Claude Code. Хук получает от Claude Code готовое предложение правила (`permission_suggestions`, например `addRules` → `allow` для `Bash(git push origin main)` в `localSettings`, то есть `.claude/settings.local.json` проекта) — Utter возвращает его как `updatedPermissions` вместе с `behavior: "allow"` (так описано в документации хуков, проверено 2026-11-09). Своих правил Utter не придумывает: если предложения в запросе нет, кнопки «Всегда» для этого запроса нет.
- В режиме Claude Code, где всё разрешено без вопросов, хук просто не вызывается — карточек нет.

### 3.5 Пауза

Пункт меню в строке меню **«Пауза агентов» / «Pause agents»** (галочка). На паузе Капля не показывает агентов, запросы разрешений сразу уходят в Claude Code. Снял паузу — одна строка в острове на 4 с: «Пока была пауза: 2 агента закончили, 1 ждёт тебя». Диктовка на паузе работает. Пауза не переживает перезапуск Utter.

### 3.6 Пасхалка

5 и больше нажатий на Каплю (в ушке или в острове) за 2 с: у Капли кружится голова (глаза-спирали, румянец, покачивание) 3 с, строка «Слишком много тычков. Дай секунду — вернусь к работе через три секунды.» / «Too many pokes. Give me a sec — back in three seconds.» Во время записи не срабатывает.

### 3.7 Задача для агента голосом

- Третья клавиша **«Задача»** в разделе «Клавиши», по умолчанию **правый ⌃**; режимы «Удержание»/«Нажатие» те же, что у диктовки.
- Путь как у диктовки (живой черновик в острове, если включён Gemini Live), а на чистовой обработке — свой промпт: оформить сказанное как задачу для ИИ-агента на том же языке — суть одной строкой, затем пункты (что сделать, детали, ограничения), без выдуманных фактов и без вступлений. Капля в острове — с отдельным цветом режима (подберём вместе с остальными цветами).
- История помечает такие записи режимом «Задача».

## 4. Устройство

- **`utter-agent`** — маленькая вторая программа внутри `Utter.app/Contents/MacOS` (тот же Rust-проект, отдельный bin, подписана вместе с приложением). Вызывается агентами, читает событие (stdin у Claude Code, последний аргумент у Codex), отправляет его Utter через Unix-сокет `<данные приложения>/agents.sock` (права 0600) и выходит. Для `PermissionRequest` ждёт ответ. Если Utter не запущен или сокет молчит 300 мс — тихо выходит, агент не замедляется. В режиме Codex после отправки запускает прежнюю команду `notify` с теми же аргументами.
- **Модуль `agents` в Utter:** приём сокета, разбор событий в общий вид (`AgentEvent { agent, session, project, kind, detail }`), реестр сессий (состояние, шаг X из Y, последние действия, когда видели), установка/снятие хуков (`claude_hooks`, `codex_notify` — чистые функции над текстом файла), итог (`summary`), определение приложения-хозяина.
- **Какие события Claude Code слушаем:** `UserPromptSubmit` (работает), `PreToolUse` (лента: инструмент + файл/команда, коротко), `PostToolUse` для списка задач (шаг X из Y), `Notification` (ждёт ответа), `PermissionRequest` (разрешение), `Stop` (готово), `SessionEnd` (убрать). Точные имена и форматы сверяются с документацией Claude Code в первой задаче плана.
- **Сессии без событий** дольше 30 мин в состоянии «работает» гаснут (агент упал или закрыт).
- **Остров:** новый канал `overlay://agents` с моделью для страницы; что показывать (ушки, раскрытие, карточка) решает чистая модель на стороне страницы (`overlay/agents/agentIsland.ts`), как `dropModel`. Окно острова принимает клики только пока видна карточка с кнопками или курсор над ушками (иначе клики проходят насквозь, как сейчас). Наведение определяется опросом положения курсора, когда агенты есть.
- **Настройки:** `agents: { claude_code: bool, codex: bool, summary: bool }`, `agents_codex_prev_notify: Option<Vec<String>>`, `hotkeys.task: KeyId` (по умолчанию `RightCtrl`); `Mode::Task`.

## 5. Ошибки и крайние случаи

- Файл агента не читается или повреждён → не трогаем, сообщение в «Агентах».
- Агент удалён → переключатель остаётся, но «Не нашёл Claude Code на этом Mac».
- Пользователь сам поправил наши строки → при запуске восстанавливаем только свои, чужое не трогаем.
- Обновление Utter не меняет путь → хуки продолжают работать; перенос `.app` → самопроверка переписывает путь.
- Сокет занят старым процессом → удаляем и создаём заново при запуске.
- Строка итога не пришла за 3 с → первая фраза.
- Два запроса разрешения сразу → по очереди, каждый со своим отсчётом.

## 6. Проверки

- **Rust (TDD):** разбор событий Claude Code и Codex по образцам; установка/снятие хуков — сохраняет чужое, повторная установка не дублирует, восстановление прежнего `notify`; реестр сессий и переходы; гашение по таймауту; запасной итог; `utter-agent` с временным сокетом (нет Utter → выходит < 300 мс; разрешение → ждёт и возвращает ответ; Codex → вызывает прежнюю команду).
- **Vitest:** модель острова агентов (ушки, точки, раскрытие, очередь с диктовкой, пауза, пасхалка), раздел «Агенты», шаг онбординга.
- **Вживую с пользователем:** новая сессия Claude Code → «работает», лента, «готово» с итогом на другом рабочем столе; запрос разрешения (в режиме с вопросами) → ответ из острова; Codex → «готово»; пауза и строка после неё; пасхалка; «Открыть»; шаг онбординга; клавиша «Задача» в окне агента.

## 7. Не входит

Чаты Claude/ChatGPT и Cowork; файлы и чат в острове; вкладки острова; панель сервисов; эффектное появление со звёздочками; окончательные цвета (отдельный шаг с пользователем).

**Изменено пользователем по ходу живой проверки** (эти пункты заменяют §3.2, §3.6, §3.7, где отличаются):
- Цвета — логотип Figma, вариант F2: работает `#1ABCFE`, ждёт `#FF7262`, закончил `#0ACF83`, режим «Задача» `#A259FF`.
- Ушки: точка состояния на Капле — поверх неё, 7 pt; в правом ушке всегда три цвета углом (первый, справа второй, под первым третий), текущий мерцает; пока подключён хоть один агент, три цвета видны и без работы (на Капле тогда точки нет). Выключение агента сразу убирает его сессии.
- Раскрытый остров — макет 2026-11-09: большая Капля (44 pt) слева, справа проект жирным и состояние серым, отлив цветом состояния из правого нижнего угла; высота — по содержимому. Команда в карточке разрешения — целиком (перенос, прокрутка), рядом с «Всегда» — текст правила.
- Наведение раскрывает остров сразу: глобальный монитор движений мыши у верхнего края будит наблюдателя; раскрытие агентского острова — пружина 0,28 с (остров диктовки не менялся). Свободные ушки при наведении показывают «Все агенты свободны».
- Окно ловит нажатия только прямо над кнопками, строками и Каплей и никогда в верхней полосе 36 pt: иначе у приложения на весь экран не пряталась полоска меню и заголовка (причина подтверждена опытом).
- Пасхалка: каждое нажатие — «щекотка» (улыбка, подскок, покачивание 0,45 с), пятое за 2 с — головокружение; текст острова не выделяется.
- Клавиша «Задача»: по умолчанию не назначена (у MacBook нет правого ⌃); горячей может быть любая клавиша, кроме Esc (левые модификаторы, буквы — печатная клавиша глотается, настройки предупреждают).
- Codex не проверялся вживую (у пользователя нет подписки).

**Проверено вживую:** подключение и выключение Claude Code (чужие ключи и права 0600 сохраняются, файл возвращается байт в байт); «работает», «закончил» с итогом, «Открыть» (нашёл Claude.app); карточка разрешения на пробном запросе (30 с → без решения; «Всегда» → правило Claude Code ушло как `updatedPermissions`); пауза и строка после неё; пасхалка; клавиша «Задача»; полоска приложения прячется. **Не проверено:** настоящий диалог разрешения Claude Code, Codex, «Открыть» для Терминала/VS Code, несколько агентов сразу.
