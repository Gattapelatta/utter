# «Капля и ИИ-агенты» — итог выполнения (2026-11-10)

Спецификация `docs/superpowers/specs/2026-11-09-agent-drop-design.md` (итоги и изменения пользователя — §8), план `2026-11-09-agent-drop.md`. Выполнено Native (executing-plans); журнал (git-ignored) удалён, его решения — здесь.

## Финальный обзор

Свежий обзор всей ветки (opus): «With fixes». Исправлено с тестами: зависание (замок `shown` держался во время вызовов на главный поток), обрезанная команда в карточке разрешения и невидимое правило «Всегда», карточка, которая не закрывалась после ухода помощника, опрос 10 раз в секунду ради зелёной точки, хуки из `/Volumes` и AppTranslocation (и безвредная команда, если Utter удалён), расширение прав файлов 0600 → 0644, второй `notify` в настройках Codex (теперь итог проверяется парсером TOML), «1 закончили, 0 ждут», бесконечный цикл приёма сокета при ошибке.

**Отложенные мелочи:**
- ошибки «не подключено» и ошибки чтения показываются как «файл повреждён»;
- комментарий после `]` в строке `notify` теряется;
- у соединения с сокетом нет таймаута чтения (локальный клиент без перевода строки держит задачу); путь сокета длиннее 104 байт только пишется в журнал;
- markdown в ответе модели для строки итога не снимается.

## Решения по ходу (действующие)

- Язык событий — `tray::Lang` (уже разрешённый RU/EN), не `UiLanguage`.
- Шаги «X из Y» — из `TodoWrite` и из инструмента плана приложения Claude (`mcp__ccd_turn__update_plan`, целые списки); пошаговые TaskCreate/TaskUpdate не учитываются (на новых моделях их нет по умолчанию).
- `PermissionRequest` для AskUserQuestion/ExitPlanMode — «ждёт ответа», без кнопок; Notification — только `idle_prompt` и `agent_needs_input`; действия MCP-инструментов в ленту не попадают.
- Codex: строка `notify` без прежней — в самое начало файла; при выключении возвращается цепочка из файла, сохранённое значение — только если цепочки нет.
- `serde_json` с `preserve_order` (порядок ключей пользователя).
- `utter-agent`: Tauri сам кладёт все `[[bin]]` в `Contents/MacOS`; для universal `scripts/release.sh` склеивает его `lipo`. Помощник не линкует `utter_lib` (`wire.rs` через `#[path]`), шлёт предков (pid) — Utter сам находит приложение через NSRunningApplication; стартует за ~5 мс.
- В провайдер уходит максимум 4000 знаков последнего сообщения.
- Карточки: 6 с / 4 с считаются с момента показа (`card_shown`); пауза сбрасывает открытые запросы «без решения»; просмотренные готовые сессии уходят из вида; после паузы считаются сессии, не события.
- «Открыть» — `open -b <bundle id>` (переключает на рабочий стол приложения); проверено для Claude.app.
- Карточка агента поднимает окно и при выключенных ушках (приложение на весь экран).
- События выключенного агента игнорируются; `reconcile` — при запуске и при изменении `agents`; файлы пишутся только при изменении, через символические ссылки, с прежними правами и прежним последним переводом строки.
- Пункт «Пауза агентов» в меню есть, только пока подключён агент; его удаление снимает паузу.
- Шаг онбординга «Подключи агентов» показывает только найденных агентов; «Далее» с выключенными переключателями — пропуск.
- Клавиша «Задача»: в онбординге не показывается (новичок сначала учит диктовку); по умолчанию не назначена (решение пользователя); «Задача» при ошибке вставляет сырой текст и проверяет галлюцинации, как диктовка.
- Окно острова ловит нажатия только над зонами, которые сообщает страница (`agent_hit_zones`), и никогда в верхних 36 pt.
